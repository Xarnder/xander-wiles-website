# Guildford Cathedral 360°

This page uses the shared viewer in `../shared/`. It does not contain its own copy of the viewer.

Open it at `/pages/360_image_viewer/guildford-cathedral/`.

## Images

`images/manifest.json` lists the collection. Each entry has two local files:

- `preview` is a file in `images/Low_Res_Guildford_Cathedral/`. The viewer shows this first.
- `full` is the matching file in `images/Full_Res_Guildford_Cathedral/`. The viewer fetches it in the background and swaps it in when it has loaded.

Paths are filenames under `images/`, not remote URLs. The main 360° viewer includes this same manifest as a Guildford Cathedral group, alongside its other images. This page lists only the cathedral photographs.
