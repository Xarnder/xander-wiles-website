# ALDESCA clothing image prompts

Nine original images generated using the built-in `image_gen.imagegen` tool, one call per image, with `transparent_background: false`. No external image inputs, CLI or API fallback were used. The models in the editorial photograph are generated adults.

Original generated PNGs are copied into this directory. Optimized WebP files and 480px-wide variants live in `../../static/images/clothing`; their separate manifest is `../../src/lib/assets/clothing-asset-manifest.json`. The homeware photograph data is unchanged. Re-run `node scripts/prepare-clothing-assets.mjs` from the ALDESCA project to reproduce optimized assets without making generation calls.

These are demonstration fashion images, not photographs of manufactured inventory. Fabric appearance is visual styling, not verified material composition. The hero and studio product photographs were generated independently; small design differences may exist.
