Quest 3 AR Controls Guide

IN-HEADSET PASSTHROUGH AR CONTROLS
  • Button 'B' / 'Y' Toggle In-Game 3D Floating Menu & Controls Card
  • Right Thumbstick (↕) Scroll through 3D Model Library menu items
  • Button 'A' / 'X' Select model / toggle Room Mode / Scaling in menu
  • Trigger Aim at the scanned floor or furniture and spawn the selected model
  • Room Scan Uses Quest Space Setup / room mesh. If none is found, Space Setup opens so you can scan the room
  • Hold Button 'A' / Grip Drag model across real surfaces in your room
  • Left Thumbstick (↕) Lift or lower model height in 3D space
  • Right Thumbstick (↔) Rotate model around vertical axis
  • Right Thumbstick (↕) Scale model size up / down
DESKTOP / 2D CONTROLS
  • Left Click + Drag Orbit camera around model
  • Right Click + Drag Pan camera
  • Scroll Wheel Zoom in & out
SPLAT COMPARE
  • Compare Splats Pick two Gaussian splats, then view them from one shared camera
  • Dual windows Both splats on screen; orbiting one view moves the other identically
  • Single view One splat on the GPU at a time. Space / 1 / 2 to switch without moving the camera
  • P / Snapshot Save PNGs of both splats from the current shared camera pose
  • Esc Close compare setup or exit compare
