  • ⌘/Ctrl+F searches inside the open markdown file.
  • ⌘/Ctrl+S saves the open file.
  • Preview shows formatted markdown and ranked lists (tap the pen to edit a list). Use Edit here then tap text to jump into Raw at that spot. List focuses on lists only. Raw is the full file text.
  • Unsaved edits autosave to Drive after 10 seconds of inactivity — the slim bar under the mode switcher counts down remaining idle time. You can still tap Save anytime. Tapping Save can show a Saving in progress lock (turn this off in Settings if you really need to). Autosave never blocks the screen. Undo / Redo in the Edit toolbar (and ⌘/Ctrl+Z) still work after autosave. For older cloud versions after reload, open Version history from the Edit ⋮ menu. Use Name this version… for a permanent checkpoint.
  • Date tags use {{date:YYYY-MM-DD}} (smart formats like 3 Aug 2026 also work). They stay in Raw; Preview hides them unless you turn on Show dates in the Edit ⋮ menu. New list items (normal and custom) get today’s tag automatically. Use Insert date for one tag, or Fill missing list dates… to stamp every undated list item with the file’s created date or a custom date.
  • Export a list as JSON from To-Do List / Story Manager, then use Import here — tap Preview content and choose Above / Below to place it.
  • Use List / Preview for ranked mdlist blocks.
  • Tap ⋮ in Finder to Pin a note or folder — Pinned opens first after sign-in.
